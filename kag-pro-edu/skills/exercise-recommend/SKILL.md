# KAG-Pro 个性化推荐

## 使用场景
- 学生积累了错题历史后需要针对性练习
- 需要基于知识图谱的前置知识分析构建学习路径
- 需要间隔复习调度

## 工作流程
1. 确保 diagnose 已被调用至少2次（积累错题历史）
2. 调用 `kag_pro_recommend` MCP 工具，传入推荐数量
3. 工具自动完成：薄弱点分析 → KG前置知识查找 → LLM生成练习 → 学习路径构建
4. 返回结果包含：薄弱知识点、KG补充、练习题列表、学习路径

## Qoder 技能集成

### genui 集成
调用 `kag_pro_recommend` 后，可使用 genui 的 `show_widget` 工具：
- 将练习题渲染为可交互的答题卡片
- 将学习路径渲染为可视化步骤图
- 展示薄弱知识点雷达图

### schedule 集成
当某知识点 mastery < "proficient" 时：
- 创建每日定时练习任务（每天3道题）
- 创建间隔复习提醒（基于BKT遗忘曲线）
- 创建周度学习报告生成任务

## 输出规范
- 练习题按难度递增排列（基础 → 中等 → 提高）
- 每道题标注考察知识点
- 学习路径：先修知识 → 重点攻克 → 避免易错

## 示例
调用：kag_pro_recommend(count=3)
返回：weak_points=[{"knowledge_point":"导数极值","error_count":2}], 
      exercises=[{"content":"1. (基础) 求f(x)=x³-3x的极值..."}],
      learning_path=["复习先修知识: 函数", "重点攻克: 导数极值", "注意避免: 导数零点≠极值点"]
