# KAG-Pro 智能问答

## 使用场景
- 学生提出学科知识问题（数学、物理、化学、生物等）
- 需要基于教材内容给出准确回答
- 需要学段适配的语言风格（小学/初中/高中）
- 需要知识图谱补充的前置知识和易错点

## 工作流程
1. 调用 `kag_pro_query` MCP 工具，传入学生问题和可选的 verify 参数
2. 工具自动完成：学段检测 → KG增强检索 → LLM生成 → 事实验证
3. 返回结果包含：答案、学段、来源文档、知识图谱补充、验证信息

## 输出规范
- 答案不含 Markdown 符号（不要用 **加粗**、- 列表、`代码块`）
- 选择题先给答案再逐项解析，格式如 "A. xxx → 这是xxx现象"
- 每个要点单独换行，使用自然段落分隔
- 如果资料不足以回答，用自己的知识直接作答

## 验证
- 可使用 chrome-devtools 技能验证前端问答界面的答案渲染
- 检查 /api/v2/query 端点的 API 响应时间
- 验证中文编码在 SSE 流式输出中的正确性

## 示例
学生问："什么是导数的极值判定方法？"
调用：kag_pro_query(question="什么是导数的极值判定方法？", verify=true)
返回：答案包含导数极值判定步骤、学段为高中、来源为教材片段、KG补充前置知识"函数"和"极限"
