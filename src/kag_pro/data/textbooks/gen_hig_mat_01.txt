高中数学 - 集合的概念与运算

一、集合的概念与表示
集合是数学中最基本的概念，我们把所要研究的一些确定对象的全体称为一个集合，通常用大写字母 $A,B,C$ 表示。集合中的每个对象称为该集合的元素，用小写字母 $a,b,c$ 表示。若 $a$ 是集合 $A$ 的元素，记作 $a \in A$；若 $a$ 不是 $A$ 的元素，记作 $a \notin A$。集合中的元素必须满足确定性、互异性和无序性。

常用的数集有：非负整数集（自然数集）$\mathbb{N}$，正整数集 $\mathbb{N}^*$ 或 $\mathbb{N}_+$，整数集 $\mathbb{Z}$，有理数集 $\mathbb{Q}$，实数集 $\mathbb{R}$。表示集合常用列举法，如 $A=\{1,2,3,4\}$，和描述法，如 $B=\{x \mid x>2, x \in \mathbb{R}\}$。不含任何元素的集合称为空集，记作 $\varnothing$。

二、集合间的基本关系
若集合 $A$ 的每一个元素都属于集合 $B$，则称 $A$ 是 $B$ 的子集，记作 $A \subseteq B$（或 $B \supseteq A$）。如果 $A \subseteq B$ 且 $B \subseteq A$，那么集合 $A$ 与 $B$ 相等，记作 $A = B$。如果 $A \subseteq B$ 但 $A \neq B$，则称 $A$ 是 $B$ 的真子集，记作 $A \subsetneqq B$。任何一个集合都是它自身的子集，空集是任何集合的子集。

例1 已知集合 $A=\{1,3,\sqrt{m}\}$，$B=\{1,m\}$，且 $A=B$，求 $m$ 的值。
分析：由集合相等，元素完全相同，且满足互异性。$A$ 中有 $\sqrt{m}$，$B$ 中有 $m$。可能出现 $\sqrt{m}=3$ 或 $\sqrt{m}=m$。若 $\sqrt{m}=3$，得 $m=9$，此时 $A=\{1,3,3\}$ 与互异性矛盾，舍去。若 $\sqrt{m}=m$，解得 $m=0$ 或 $m=1$。$m=1$ 时 $A=\{1,3,1\}$ 违反互异性；$m=0$ 时 $A=\{1,3,0\}$，$B=\{1,0\}$，不相等。因此此题无解，但过程说明需兼顾相等与互异性。

三、集合的运算
并集：由所有属于集合 $A$ 或属于集合 $B$ 的元素组成的集合，记作 $A \cup B$，即
$$A \cup B = \{x \mid x \in A \text{ 或 } x \in B\}.$$
交集：由所有既属于 $A$ 又属于 $B$ 的元素组成的集合，记作 $A \cap B$，即
$$A \cap B = \{x \mid x \in A \text{ 且 } x \in B\}.$$
补集：在研究某个全集合 $U$ 时，由 $U$ 中所有不属于 $A$ 的元素组成的集合称为 $A$ 的补集，记作 $\complement_U A$，即
$$\complement_U A = \{x \mid x \in U \text{ 且 } x \notin A\}.$$

例2 设全集 $U=\mathbb{R}$，集合 $A=\{x \mid x^2-3x+2 \leq 0\}$，$B=\{x \mid 1 < x \leq 4\}$。求 $A \cap B$，$A \cup B$，$\complement_U A$。
解：解不等式 $x^2-3x+2 \leq 0$ 得 $1 \leq x \leq 2$，即 $A=\{x \mid 1 \leq x \leq 2\}$。那么：
$A \cap B = \{x \mid 1 < x \leq 2\}$，
$A \cup B = \{x \mid 1 \leq x \leq 4\}$，
$\complement_U A = \{x \mid x < 1 \text{ 或 } x > 2\}$。

例3 已知集合 $A=\{x \mid -2 \leq x \leq 5\}$，$B=\{x \mid m+1 \leq x \leq 2m-1\}$，若 $B \subseteq A$，求实数 $m$ 的取值范围。
分析：$B$ 是 $A$ 的子集，需分 $B$ 为空集和非空集讨论。当 $B = \varnothing$ 时，$m+1 > 2m-1$，即 $m < 2$。当 $B \neq \varnothing$ 时，需满足
$$m+1 \leq 2m-1,\ m+1 \geq -2,\ 2m-1 \leq 5,$$
解得 $2 \leq m \leq 3$。综上，$m$ 的取值范围是 $\{m \mid m \leq 3\}$。

四、常见错误辨析
错误1 混淆“属于”与“包含于”关系。如写出 $\{1\} \in \{1,2\}$ 是错误的。元素与集合之间用 $\in$，集合与集合之间用 $\subseteq$。正确写法应为 $\{1\} \subseteq \{1,2\}$ 或 $1 \in \{1,2\}$。纠正方法：看清符号左边是元素还是集合，再用对应的关系符号。

错误2 忽视空集的特殊情况。在子集问题中忘记讨论子集为空集，或认为空集没有子集。实际上，$\varnothing \subseteq A$ 对任何集合 $A$ 成立，且 $\varnothing$ 只有一个子集即自身。纠正方法：遇到“子集”“包含”条件时，首先考虑空集是否满足；书写空集符号务必规范，避免与 $\{0\}$ 混淆。
