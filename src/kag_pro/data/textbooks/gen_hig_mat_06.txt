高中数学 - 指数函数与对数函数

一、指数函数

一般地，形如 $y = a^x$（$a>0$ 且 $a\neq 1$）的函数叫做指数函数，其中 $x$ 是自变量，定义域为 $\mathbb{R}$。底数 $a$ 决定了函数的单调性：当 $a>1$ 时，函数在 $\mathbb{R}$ 上单调递增；当 $0<a<1$ 时，函数在 $\mathbb{R}$ 上单调递减。所有指数函数的图像都过定点 $(0,1)$，且值域为 $(0,+\infty)$，即 $y$ 恒为正值。图像向上无限延伸，向下以 $x$ 轴为渐近线但永不接触。

二、对数函数

若 $a^b = N$（$a>0$，$a\neq 1$），则称 $b$ 为以 $a$ 为底 $N$ 的对数，记作 $b = \log_a N$，其中 $N$ 称为真数，必须满足 $N>0$。形如 $y = \log_a x$（$a>0$ 且 $a\neq 1$）的函数叫做对数函数，定义域为 $(0,+\infty)$，值域为 $\mathbb{R}$。图像恒过定点 $(1,0)$，当 $a>1$ 时单调递增，当 $0<a<1$ 时单调递减。对数函数与同底的指数函数互为反函数，它们的图像关于直线 $y=x$ 对称。

常用的运算性质（$M>0$，$N>0$）有：
$$\log_a (MN) = \log_a M + \log_a N$$
$$\log_a \frac{M}{N} = \log_a M - \log_a N$$
$$\log_a M^n = n \log_a M$$
换底公式为 $\log_a b = \frac{\log_c b}{\log_c a}$，特别地有 $\log_a b = \frac{1}{\log_b a}$。

三、典型例题与常见误区

例题1：比较 $1.5^{2.5}$ 与 $1.5^{3.2}$ 的大小。
解：设 $y=1.5^x$，底数 $1.5>1$，函数在 $\mathbb{R}$ 上单调递增。因为 $2.5 < 3.2$，所以 $1.5^{2.5} < 1.5^{3.2}$。

例题2：解方程 $\log_2 (x-1) + \log_2 (x+1) = 3$。
解：首先真数须满足 $x-1>0$ 且 $x+1>0$，得 $x>1$。利用对数性质合并：$\log_2 [(x-1)(x+1)] = 3$，即 $\log_2 (x^2-1) = 3$，化为指数形式得 $x^2-1 = 2^3 = 8$，$x^2 = 9$，解得 $x = 3$ 或 $x = -3$。结合 $x>1$，舍去 $x=-3$，原方程解为 $x=3$。

例题3：求函数 $y = \log_{\frac{1}{2}} (x^2-3x+2)$ 的单调递减区间。
解：由真数大于零得 $x^2-3x+2>0$，解得 $x<1$ 或 $x>2$，此即定义域。底层函数 $u = x^2-3x+2$ 在 $(-\infty, 1)$ 上单调递减，在 $(2,+\infty)$ 上单调递增。外层函数 $y = \log_{\frac{1}{2}} u$ 是减函数。根据“同增异减”原则：$x\in (-\infty, 1)$ 时，$u$ 减、外层减，复合后为增；$x\in (2,+\infty)$ 时，$u$ 增、外层减，复合后为减。故所求单调递减区间为 $(2,+\infty)$。

常见误区与纠正：

误区一：解对数方程时不检验真数条件。如例题2中，学生直接将 $\log_2 (x-1) + \log_2 (x+1) = 3$ 化为 $(x-1)(x+1)=8$，解出 $x=\pm 3$ 便认为都是解。纠正方法：解对数方程必须“定义域先行”，做真数大于零的限制，最后一定要进行根的取舍。

误区二：混淆对数运算性质。常有错误：$\log_a (M+N) = \log_a M + \log_a N$ 或 $\log_a (MN) = \log_a M \cdot \log_a N$。纠正方法：牢记对数运算仅对乘积、商和幂进行拆分，加法不能拆成对数和。可用特殊值检验，如 $\log_2 (2+2) = \log_2 4 = 2$，而 $\log_2 2 + \log_2 2 = 2$ 此处恰巧相等，但换 $M=2$, $N=3$，$\log_2 5$ 并不等于 $\log_2 2 + \log_2 3$ 的计算值，因此切不可推广。
