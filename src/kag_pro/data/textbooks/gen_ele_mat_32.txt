小学数学 - 长方体和正方体

一、认识长方体和正方体  
我们生活中有许多长方体形状的物体，比如教室里的粉笔盒、储蓄罐、冰箱的包装箱。长方体有6个面，每个面都是长方形（也可能有两个相对的面是正方形），相对的面形状完全相同。它有12条棱，可以分成3组，每组4条棱的长度相等。长方体还有8个顶点。  
如果长方体的所有棱长都相等，这时6个面都变成了大小一样的正方形，这样的立体图形就是正方体。正方体是特殊的长方体。  

二、长方体和正方体的表面积  
表面积指的是立体图形所有面的面积之和。  
长方体的表面积公式：设长、宽、高分别为 $a$、$b$、$h$，则表面积 $S = 2(ab + ah + bh)$。  
正方体的表面积公式：设棱长为 $a$，则表面积 $S = 6a^2$。  

例1 一个长方体包装盒，长25厘米，宽20厘米，高10厘米。做这样一个包装盒至少需要多少平方厘米的硬纸板？  
解：$a=25$，$b=20$，$h=10$。  
$S = 2\times(25\times20 + 25\times10 + 20\times10)$  
$= 2\times(500 + 250 + 200)$  
$= 2\times950 = 1900$ (平方厘米)  
答：至少需要1900平方厘米的硬纸板。  

例2 一个正方体鱼缸的棱长是4分米，制作这个鱼缸至少需要多少平方分米的玻璃？（鱼缸无盖）  
分析：鱼缸没有盖子，所以只算5个面。  
解：正方体一个面的面积是 $4\times4 = 16$ 平方分米，5个面为 $16\times5 = 80$ 平方分米。  
如果用公式调整，就是 $S = 5a^2 = 5\times4^2 = 5\times16 = 80$ 平方分米。  
答：至少需要80平方分米的玻璃。  

三、长方体和正方体的体积  
物体所占空间的大小叫做体积。  
长方体的体积公式：$V = a b h$  
正方体的体积公式：$V = a^3$  
长方体（正方体）的体积也可以用底面积乘高计算，即 $V = S_{\text{底}} h$。  

例3 一个长方体水箱，从里面量长6分米，宽5分米，深4分米。水箱的容积是多少升？  
解：容积的计算方法与体积相同，$V = 6\times5\times4 = 120$（立方分米）。  
因为1立方分米 = 1升，所以容积是120升。  
答：水箱的容积是120升。  

四、常见错误及纠正  
错误1：计算无盖物体表面积时，忘记减少面的数量。  
比如例2中，学生可能直接用 $6a^2$ 算出所有6个面，得到96平方分米。纠正方法：提醒学生先观察实际物体有几个面需要材料，鱼缸、教室粉刷（去掉门窗地面）、通风管等都要具体分析，不要直接套完整公式。  

错误2：体积和表面积单位混淆。  
有同学算完体积写“表面积是120平方厘米”。正确理解：体积用立方单位（立方厘米、立方分米、立方米），表面积用平方单位。可以想象一个面铺开是面积，整个所占空间才是体积，两者意义完全不同。
