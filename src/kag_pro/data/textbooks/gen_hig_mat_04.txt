高中数学 - 二次函数与不等式

二次函数与一元二次不等式的关系，本质上是利用函数图像（抛物线）与x轴的位置关系来求解。

对于二次函数 \(f(x) = ax^2 + bx + c\ (a>0)\)，设相应方程 \(ax^2 + bx + c = 0\) 的判别式为 \(\Delta\)，两根为 \(x_1 \le x_2\)（若存在实根）。通过图像可得解集口诀：“大于取两边，小于取中间”。

- 若 \(\Delta > 0\)，图像与x轴有两个交点，\(f(x)>0\) 的解集为 \(\{x|x < x_1 \text{ 或 } x > x_2\}\)；\(f(x)<0\) 的解集为 \(\{x|x_1 < x < x_2\}\)。
- 若 \(\Delta = 0\)，图像与x轴相切于 \(x_0 = -\frac{b}{2a}\)，\(f(x) > 0\) 的解集为 \(\{x| x \neq x_0\}\)；\(f(x) < 0\) 的解集为空集。
