初中数学 - 函数初步

一、函数的概念

在一个变化过程中，如果有两个变量 x 和 y，对于 x 的每一个确定的值，y 都有唯一确定的值与其对应，那么就说 y 是 x 的函数。其中 x 是自变量，y 是因变量。

函数的表示方法：
1. 解析法（公式法）：如 y = 2x + 1
2. 列表法：列出 x 和 y 的对应值
3. 图象法：在坐标系中画出函数图象

二、一次函数

形如 y = kx + b（k ≠ 0）的函数叫做一次函数。

- k 叫做斜率，表示直线的倾斜程度。k > 0 时直线从左到右上升；k < 0 时下降。
- b 叫做截距，表示直线与 y 轴的交点的纵坐标。即当 x=0 时 y=b。

一次函数的图象是一条直线。

例如：y = 2x + 1，斜率 k=2，截距 b=1。
当 x=0 时 y=1；当 x=1 时 y=3；当 x=2 时 y=5。

三、二次函数

形如 y = ax² + bx + c（a ≠ 0）的函数叫做二次函数。图象是一条抛物线。

- 当 a > 0 时，抛物线开口向上，有最小值
- 当 a < 0 时，抛物线开口向下，有最大值

顶点坐标公式：(-b/2a, (4ac-b²)/4a)
对称轴：x = -b/2a

例如：y = x² - 4x + 3
这里 a=1, b=-4, c=3
顶点：x = -(-4)/(2×1) = 2, y = (4×1×3-16)/(4×1) = -1
所以顶点是 (2, -1)，开口向上。

四、二次函数与一元二次方程的关系

二次函数 y = ax² + bx + c 的图象与 x 轴的交点，就是方程 ax² + bx + c = 0 的根。
- Δ > 0：抛物线与 x 轴有两个交点（两个不相等的实数根）
- Δ = 0：抛物线与 x 轴有一个交点（两个相等的实数根，相切）
- Δ < 0：抛物线与 x 轴没有交点（没有实数根）
