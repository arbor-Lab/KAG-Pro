初中化学 - 化学反应基础

一、物理变化与化学变化

物理变化：没有生成新物质的变化。例如：水结冰、玻璃破碎、铁块被拉成铁丝。
化学变化：生成了新物质的变化。例如：铁生锈、木头燃烧、食物腐败。

化学变化的特征：有新物质生成，常伴随发光、发热、变色、放出气体、生成沉淀等现象。

二、化学反应速率

化学反应速率表示化学反应进行的快慢。

影响化学反应速率的因素：
1. 温度：温度越高，反应速率越快
2. 浓度：反应物浓度越大，反应速率越快
3. 催化剂：能改变反应速率但本身质量和化学性质不变的物质
4. 接触面积：反应物接触面积越大，反应速率越快（如粉末比块状反应快）

例如：铁在潮湿空气中比在干燥空气中更容易生锈。
原因是水参与了铁的锈蚀反应，提高了反应物的有效接触。

三、化学方程式

用化学式表示化学反应的式子叫做化学方程式。

书写原则：
1. 以客观事实为依据
2. 遵守质量守恒定律（反应前后原子种类和数目不变）

例如：氢气燃烧
2H₂ + O₂ → 2H₂O
表示：每 2 个氢分子和 1 个氧分子反应，生成 2 个水分子。

配平化学方程式的常见错误：
- 忘记配平（反应前后原子数不等）
- 配平后忘记补全反应条件（如点燃、加热、催化剂等）
- 将化学式改错（不能随意改变化学式来配平，只能改系数）

四、常见的化学反应类型

1. 化合反应：A + B → AB（多种物质生成一种）
   例如：C + O₂ → CO₂

2. 分解反应：AB → A + B（一种物质分解成多种）
   例如：2H₂O → 2H₂↑ + O₂↑（电解水）

3. 置换反应：A + BC → AC + B（单质与化合物反应）
   例如：Fe + CuSO₄ → FeSO₄ + Cu

4. 复分解反应：AB + CD → AD + CB（两种化合物交换成分）
   例如：NaOH + HCl → NaCl + H₂O
