高中数学 - 双曲线

一、双曲线的定义

平面内与两个定点 $F_1$，$F_2$ 的距离之差的绝对值等于常数（记作 $2a$，且 $0 < 2a < |F_1F_2|$）的点的轨迹叫做双曲线。这两个定点称为双曲线的焦点，两焦点间的距离 $|F_1F_2|$ 称为焦距，记作 $2c$，$c>a>0$。

从定义可以看出，双曲线上的任意一点 $P$ 始终满足 $| |PF_1| - |PF_2| | = 2a$。若去掉绝对值，则 $|PF_1| - |PF_2| = \pm 2a$ 只表示双曲线的一支。这正是学生容易遗漏绝对值的根源。

二、双曲线的标准方程与几何性质

取过两焦点 $F_1(-c,0)$，$F_2(c,0)$ 的直线为 $x$ 轴，线段 $F_1F_2$ 的垂直平分线为 $y$ 轴，则可推导出焦点在 $x$ 轴上的双曲线标准方程：
$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$$
其中 $b^2 = c^2 - a^2$，即 $c^2 = a^2 + b^2$。焦点坐标为 $(\pm c,0)$，顶点坐标为 $(\pm a,0)$，实轴长 $2a$，虚轴长 $2b$。

类似地，焦点在 $y$ 轴上的双曲线标准方程为：
$$\frac{y^2}{a^2} - \frac{x^2}{b^2} = 1$$
此时焦点为 $(0,\pm c)$，顶点为 $(0,\pm a)$，$c^2 = a^2 + b^2$ 不变。

双曲线的渐近线是它无限接近但永不相交的直线。对 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$，渐近线方程为 $y = \pm \frac{b}{a}x$；对 $\frac{y^2}{a^2} - \frac{x^2}{b^2} = 1$，渐近线方程为 $y = \pm \frac{a}{b}x$。离心率 $e = \frac{c}{a}$，且 $e>1$，$e$ 越大，双曲线的“开口”越开阔。

三、典型例题

例1  已知动点 $M$ 到 $F_1(-5,0)$ 与 $F_2(5,0)$ 的距离之差的绝对值为 $6$，求点 $M$ 的轨迹方程。
解：由题意，双曲线焦点在 $x$ 轴上，$c=5$，$2a=6$，即 $a=3$。由 $c^2 = a^2 + b^2$ 得 $b^2 = 25 - 9 = 16$，故 $b=4$。所求标准方程为 $\frac{x^2}{9} - \frac{y^2}{16} = 1$。

例2  求双曲线 $9x^2 - 16y^2 = 144$ 的实轴长、虚轴长、焦点坐标、离心率及渐近线方程。
解：化标准形式 $\frac{x^2}{16} - \frac{y^2}{9} = 1$，得 $a^2=16$，$b^2=9$，即 $a=4$，$b=3$。实轴长 $2a=8$，虚轴长 $2b=6$。由 $c^2 = a^2 + b^2 = 25$ 得 $c=5$，焦点为 $(\pm 5,0)$。离心率 $e = \frac{c}{a} = \frac{5}{4}$。渐近线：$y = \pm \frac{b}{a}x = \pm \frac{3}{4}x$。

例3  斜率为 $1$ 的直线 $l$ 经过双曲线 $\frac{x^2}{3} - y^2 = 1$ 的右焦点 $F_2$，且与双曲线交于 $A$、$B$ 两点，求弦长 $|AB|$。
解：由方程知 $a^2=3$，$b^2=1$，$c^2=4$，右焦点 $F_2(2,0)$。直线方程为 $y = x - 2$。联立方程组：
$$\begin{cases} y = x - 2 \\ \frac{x^2}{3} - y^2 = 1 \end{cases}$$
代入消 $y$ 得 $\frac{x^2}{3} - (x-2)^2 = 1$，整理得 $2x^2 - 12x + 15 = 0$。设 $A(x_1,y_1)$，$B(x_2,y_2)$，则 $x_1+x_2=6$，$x_1x_2=\frac{15}{2}$，弦长
$$|AB| = \sqrt{1+k^2}\sqrt{(x_1+x_2)^2 - 4x_1x_2} = \sqrt{2}\sqrt{36 - 30} = \sqrt{2}\sqrt{6} = 2\sqrt{3}.$$

四、常见错误及纠正

错误1：忽略距离之差的“绝对值”，误认为 $|PF_1| - |PF_2| = 2a$ 就是完整的双曲线，结果只得到右支。纠正：定义中必须带绝对值，若无绝对值，方程只表示一支；解题时若题目只说“距离之差为常数”，应默认为差的绝对值，得到完整双曲线。

错误2：混淆双曲线与椭圆的 $a,b,c$ 关系。有的学生死记“椭圆中 $a$ 最大，双曲线中 $c$ 最大”，却把关系式写成 $a^2 = b^2 + c^2$。纠正：双曲线满足 $c^2 = a^2 + b^2$，焦点离中心最远；椭圆满足 $a^2 = b^2 + c^2$。可通过图形对比记忆，焦点始终在长轴或实轴端点的外侧。
