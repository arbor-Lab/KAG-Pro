初中物理 - 欧姆定律及其应用

一、欧姆定律

欧姆定律是描述电路中电流、电压和电阻三者之间关系的基本规律。在导体两端加上电压，导体中就会有电流通过。德国物理学家欧姆通过大量实验发现：导体中的电流，跟导体两端的电压成正比，跟导体的电阻成反比。这就是欧姆定律。

如果用 $I$ 表示通过导体的电流，单位是安培（A）；$U$ 表示导体两端的电压，单位是伏特（V）；$R$ 表示导体的电阻，单位是欧姆（Ω）。那么欧姆定律可以写成公式：

$$I = \frac{U}{R}$$

这个公式也可以变形为求电压 $U = IR$，以及求电阻 $R = \frac{U}{I}$。需要特别注意的是，电阻 $R$ 是导体本身的一种性质，它的大小由导体的材料、长度、横截面积和温度决定，与加在它两端的电压和通过它的电流无关。公式 $R = \frac{U}{I}$ 只是提供了一种测量或计算电阻的方法。

二、欧姆定律的应用

利用欧姆定律，我们可以解决电路中的许多实际问题。

例1：一个定值电阻两端加上3V电压时，通过它的电流为0.2A。求这个电阻的阻值。如果电压增大到6V，此时通过电阻的电流是多少？电阻的阻值又是多少？

解：根据 $R = \frac{U}{I}$，电阻的阻值 $R = \frac{3V}{0.2A} = 15Ω$。电阻是导体本身的属性，当电压变为6V时，电阻的阻值仍为15Ω。此时的电流 $I' = \frac{U'}{R} = \frac{6V}{15Ω} = 0.4A$。

例2：一个电铃正常工作时的电阻是10Ω，通过的电流为0.3A。现在手边只有一个电压为4.5V的电源，能否直接将电铃接到这个电源上？如果不能，应该怎么办？

解：电铃正常工作时需要的电压 $U_{额} = IR = 0.3A \times 10Ω = 3V$。因为电源电压4.5V高于3V，所以不能直接连接，否则会烧坏电铃。需要串联一个合适的电阻分去多余的电压。分去的电压 $U_{分} = 4.5V - 3V = 1.5V$，串联电路电流相等，所以串联电阻的阻值 $R_{串} = \frac{U_{分}}{I} = \frac{1.5V}{0.3A} = 5Ω$。

例3：在如图所示的电路中（想象一个灯泡和一个滑动变阻器串联），电源电压恒为6V，灯泡电阻为12Ω（设灯丝电阻不变）。当滑动变阻器接入电路的阻值为8Ω时，求电路中的电流和灯泡两端的电压。

解：串联电路的总电阻 $R_{总} = 12Ω + 8Ω = 20Ω$。电路中的电流 $I = \frac{U}{R_{总}} = \frac{6V}{20Ω} = 0.3A$。灯泡两端的电压 $U_{灯} = IR_{灯} = 0.3A \times 12Ω = 3.6V$。

三、常见错误理解及纠正

错误一：根据 $R = \frac{U}{I}$，认为导体的电阻与电压成正比，与电流成反比。

纠正：电阻是导体阻碍电流的性质，它的大小由导体自身的因素决定，对于一段固定的导体，其电阻通常是不变的。比如一个10Ω的电阻，无论加不加电压、有没有电流流过，它仍然是10Ω。电压增大，电流也会跟着增大，但两者的比值——电阻，是不变的。把 $R = \frac{U}{I}$ 理解成电阻的决定式是错误的，它只是欧姆定律的变形，是电阻的计算式。

错误二：在运用欧姆定律进行计算时，不注意电流、电压、电阻的同一性和同时性。

纠正：公式 $I = \frac{U}{R}$ 中的三个物理量必须是针对同一段导体、在同一时刻的值。解题时不能张冠李戴，例如把总电压除以支路电阻去求电流，或者用变化前的电压除以变化后的电阻。一定要弄清电路结构，明确每一组数据是对哪一段电路而言的。遇到动态电路，要先分析电阻的变化，再根据总电压不变去判断电流和部分电压的变化，每一步都要保证对应关系一致。
