初中物理 - 电功与电功率

一、电功
电流通过用电器时，会在内部将电能转化为其他形式的能。这个过程中，电流所做的功叫做电功，用字母 $W$ 表示。电功的大小直接反映了用电器消耗电能的多少。电功的基本计算公式为：
$$W = UIt$$
其中 $U$ 表示用电器两端的电压，单位为伏特（V）；$I$ 表示通过用电器的电流，单位为安培（A）；$t$ 表示通电时间，单位为秒（s）。电功的国际单位是焦耳，符号为 J。生活中常用“度”作为电能单位，1度 = 1千瓦时（kW·h）。换算关系为：
$$1 \ \mathrm{kW \cdot h} = 3.6 \times 10^6 \ \mathrm{J}$$
如果电路是纯电阻电路（即电能全部转化为内能的电路），结合欧姆定律 $I = \frac{U}{R}$，还可推导出两个常用公式：
$$W = I^2 R t = \frac{U^2}{R} t$$

二、电功率
电功率是描述电流做功快慢的物理量，用字母 $P$ 表示。它等于电功与做功所用时间之比，即：
$$P = \frac{W}{t}$$
将 $W = UIt$ 代入上式，可得 $P = UI$。电功率的国际单位是瓦特，简称瓦，符号为 W。常用单位还有千瓦（kW），1 kW = 1000 W。用电器上标明的功率通常是指它在额定电压下正常工作时的功率，叫做额定功率。在纯电阻电路中，电功率还可以用 $P = I^2 R$ 和 $P = \frac{U^2}{R}$ 计算。
由 $W = Pt$ 可知，当用电器的功率 $P$ 一定时，通电时间 $t$ 越长，消耗的电功 $W$ 就越多。

三、应用示例与易错提醒
示例1：一盏节能灯接在220 V的电路中，通过的电流为0.1 A。求它正常工作1小时消耗的电能是多少焦？合多少千瓦时？
解：通电时间 $t = 1 \ \mathrm{h} = 3600 \ \mathrm{s}$。
电功 $W = UIt = 220 \ \mathrm{V} \times 0.1 \ \mathrm{A} \times 3600 \ \mathrm{s} = 79200 \ \mathrm{J}$。
合千瓦时：$79200 \ \mathrm{J} \div (3.6 \times 10^6 \ \mathrm{J/kW \cdot h}) = 0.022 \ \mathrm{kW \cdot h}$。
答：消耗电能79200 J，合0.022 kW·h。

示例2：一个标有“220 V 1000 W”的电热水壶，在额定电压下工作5分钟，消耗的电能是多少焦？电流做的功是多少？
解：时间 $t = 5 \ \mathrm{min} = 300 \ \mathrm{s}$。
由公式 $W = Pt$ 得：
$W = 1000 \ \mathrm{W} \times 300 \ \mathrm{s} = 3 \times 10^5 \ \mathrm{J}$。
电流做的功与消耗的电能相等，也为 $3 \times 10^5$ J。
答：消耗电能 $3 \times 10^5$ J，电流做功 $3 \times 10^5$ J。

示例3：一个阻值为10 Ω的定值电阻，两端加上6 V电压。求它的电功率和通电2分钟产生的热量。
解：通过电阻的电流 $I = \frac{U}{R} = \frac{6 \ \mathrm{V}}{10 \ \Omega} = 0.6 \ \mathrm{A}$。
电功率 $P = UI = 6 \ \mathrm{V} \times 0.6 \ \mathrm{A} = 3.6 \ \mathrm{W}$。
通电时间 $t = 2 \ \mathrm{min} = 120 \ \mathrm{s}$。
电阻是纯电阻，电功全部转化为热量：
$W = Pt = 3.6 \ \mathrm{W} \times 120 \ \mathrm{s} = 432 \ \mathrm{J}$。
（也可直接用 $W = \frac{U^2}{R} t = \frac{(6 \ \mathrm{V})^2}{10 \ \Omega} \times 120 \ \mathrm{s} = 432 \ \mathrm{J}$）
答：电功率为3.6 W，产生的热量为432 J。

常见错误1：认为功率大的用电器消耗的电能一定多。纠正方法：电功 $W = Pt$，消耗电能的多少由功率和通电时间两个因素共同决定。功率大的用电器如果工作时间很短，它消耗的电能可能比功率小但长时间工作的用电器更少。就像一辆大功率跑车发动10秒，消耗的汽油通常比一辆小功率轿车行驶1小时要少得多。

常见错误2：使用 $W = Pt$ 计算时，不注意单位统一，误把“千瓦”和“小时”直接相乘得到“焦耳”。纠正方法：若功率用千瓦（kW），时间用小时（h），电功的单位就是千瓦时（kW·h）。若需要结果用焦耳（J），必须把功率换算成瓦（W）、时间换算成秒（s）再代入公式，或者先将得到的千瓦时数值乘以 $3.6 \times 10^6$ 换算为焦耳。计算前，务必先想清楚所需求的单位，再决定是否进行单位换算。
