初中物理 - 热机与热机效率

一、热机
热机是利用燃料燃烧释放的内能转化为机械能的装置。常见的热机有蒸汽机、内燃机、汽轮机等。四冲程汽油机的工作循环包括吸气、压缩、做功、排气四个冲程，其中只有做功冲程对外输出动力，将高温高压燃气的内能转化为活塞的机械能。

二、热机效率
热机用来做有用功的那部分能量，与燃料完全燃烧放出的能量之比，叫做热机效率，用η表示。
公式：η = Q有用 / Q总 ×100%
其中，Q有用指转化为有用机械能的部分，Q总指燃料完全燃烧所放出的热量。由于燃料燃烧放热总有一部分散失到环境中，热机效率始终小于1。

三、例题与常见错误
例题1：某汽车发动机燃烧0.2kg汽油，汽油热值4.6×10⁷J/kg，测得有用机械功为2.76×10⁶J，求该发动机的效率。
解：Q总 = mq = 0.2kg × 4.6×10⁷J/kg = 9.2×10⁶ J
η = W有用 / Q总 = 2.76×10⁶ J / 9.2×10⁶ J = 30% 
答：发动机效率为30%。

例题2：一台柴油机效率为40%，输出有用功8×10⁷J，需完全燃烧多少柴油？（柴油热值4×10⁷J/kg）
解：η = W有用 / Q总 → Q总 = W有用 / η = 8×10⁷J / 40% = 2×10⁸ J
