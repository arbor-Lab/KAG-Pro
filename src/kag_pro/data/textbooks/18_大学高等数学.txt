大学数学 - 高等数学进阶

一、多元函数微积分

多元函数 z = f(x,y) 的偏导数：
∂f/∂x：固定y，对x求导
∂f/∂y：固定x，对y求导

全微分：dz = (∂f/∂x)dx + (∂f/∂y)dy

二重积分：∬f(x,y)dxdy，计算曲顶柱体的体积。
积分次序可交换（Fubini定理）。

二、线性代数

矩阵是一个m×n的数表。矩阵运算：加法、数乘、乘法（不满足交换律）。

行列式：det(A) = |A|，是一个标量。|AB| = |A|·|B|

逆矩阵：若AB=BA=I，则B是A的逆矩阵，记作A⁻¹。
矩阵可逆的充要条件：|A| ≠ 0（满秩）。

特征值与特征向量：若Av = λv，则λ是特征值，v是特征向量。
应用：矩阵对角化、主成分分析（PCA）。

三、概率论进阶

随机变量的期望：E(X) = Σx·P(X=x)（离散）或 ∫xf(x)dx（连续）。
方差：Var(X) = E[(X-E(X))²] = E(X²) - [E(X)]²

大数定律：大量随机事件的频率趋近于概率。
中心极限定理：大量独立随机变量之和近似服从正态分布。

四、常微分方程

一阶线性微分方程：dy/dx + P(x)y = Q(x)
通解公式：y = e^{-∫Pdx} [∫Q·e^{∫Pdx}dx + C]

二阶常系数线性微分方程：ay'' + by' + cy = 0
特征方程：ar² + br + c = 0
- Δ>0：y = C₁e^{r₁x} + C₂e^{r₂x}
- Δ=0：y = (C₁+C₂x)e^{rx}
- Δ<0：y = e^{αx}(C₁cosβx + C₂sinβx)
