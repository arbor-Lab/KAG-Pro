高中数学 - 导数与微积分初步

一、导数的概念

函数 y=f(x) 在点 x₀ 处的导数，表示函数在该点的瞬时变化率。

定义：f'(x₀) = lim[h→0] (f(x₀+h) - f(x₀)) / h

几何意义：导数 f'(x₀) 表示曲线 y=f(x) 在点 (x₀, f(x₀)) 处切线的斜率。

二、基本求导公式

1. (c)' = 0（常数的导数为0）
2. (xⁿ)' = n·xⁿ⁻¹
3. (sin x)' = cos x
4. (cos x)' = -sin x
5. (eˣ)' = eˣ
6. (ln x)' = 1/x

三、求导法则

1. 和差法则：(u ± v)' = u' ± v'
2. 积法则：(uv)' = u'v + uv'
3. 商法则：(u/v)' = (u'v - uv') / v²
4. 链式法则（复合函数求导）：[f(g(x))]' = f'(g(x)) · g'(x)

四、导数与单调性

若在区间内 f'(x) > 0，则函数在该区间单调递增。
若在区间内 f'(x) < 0，则函数在该区间单调递减。

五、极值与最值

极值的必要条件：若 f(x) 在 x₀ 处取得极值且可导，则 f'(x₀) = 0。
重要：f'(x₀)=0 不一定是极值点！例如 f(x)=x³，f'(0)=0 但 x=0 不是极值点。

判断极值的方法：
1. 第一充分条件：导数由正变负为极大值，由负变正为极小值
2. 第二充分条件：f'(x₀)=0 且 f''(x₀)>0 为极小值，f''(x₀)<0 为极大值

常见错误：认为导数为零的点一定是极值点。需要检查该点两侧导数的符号变化。

六、定积分初步

定积分 ∫[a,b] f(x)dx 的几何意义是曲线与x轴围成的面积。

牛顿-莱布尼茨公式：∫[a,b] f(x)dx = F(b) - F(a)，其中F'(x)=f(x)。

例如：∫[0,2] x² dx = [x³/3]₀² = 8/3 - 0 = 8/3
