小学数学 - 质数与合数

一、认识质数与合数

一个大于1的自然数，如果只有1和它本身两个因数，这样的数叫做质数，也叫素数。例如，5的因数只有1和5，所以5是质数。

一个大于1的自然数，如果除了1和它本身还有别的因数，这样的数叫做合数。例如，6的因数有1、2、3、6，所以6是合数。

1比较特殊，它只有一个因数，所以1既不是质数，也不是合数。这样，自然数从因数的个数来分，可以分成三类：1、质数、合数。

判断一个数是质数还是合数，关键就是找它除了1和本身以外，还有没有第三个因数。比如，我们找一个数的因数时，可以一对一对地找。以12为例：$1\times12=12$，$2\times6=12$，$3\times4=12$，所以12的因数有1、2、3、4、6、12，除了1和12，还有2、3、4、6，因此12是合数。

最小的质数是2，最小的合数是4。2很特别，它既是质数，又是偶数，也是唯一的偶质数。其余的偶数，比如4、6、8、10等，都有因数2，所以它们都是合数。

二、例题与示例

例1：下面各数哪些是质数，哪些是合数？
17，22，29，35，1，87

解答：先看1，1既不是质数也不是合数。
17的因数只有1和17，所以17是质数。
22是偶数，大于2的偶数一定是合数，因为至少有因数2。实际上 $22=2\times11$，所以22是合数。
29的因数只有1和29，所以29是质数。
35个位是5，一定有因数5，$35=5\times7$，所以35是合数。
87各位数字之和是 $8+7=15$，15是3的倍数，所以87有因数3，$87=3\times29$，所以87是合数。
答：质数有17、29；合数有22、35、87；1不是质数也不是合数。

例2：在括号里填上合适的质数。
$30 = ( \ \ ) + ( \ \ )$
$30 = ( \ \ ) \times ( \ \ ) \times ( \ \ )$

解答：第一个式子要求把30写成两个质数相加的形式。我们可以从较小的质数开始尝试，$30=13+17$，13和17都是质数，符合要求。也可以填 $30=11+19$ 或 $30=7+23$ 等，答案不唯一。
第二个式子要求把30分解成几个质数相乘的形式。用短除法，$30=2\times3\times5$，2、3、5都是质数。这种把一个合数用质数相乘的形式表示出来，叫做分解质因数。

例3：小朋友分组做游戏，如果每组人数相等，且每组多于1人，不多于10人，那么15人可以分成几组？如果是13人呢？

解答：15人分组，每组人数要相等且大于1，那么每组人数应该是15的因数（1除外）。15的因数有1、3、5、15，其中大于1且不大于10的有3和5。所以可以分成每组3人，共5组；或者每组5人，共3组。13人呢？13的因数只有1和13，大于1且不大于10的因数找不到了，因为13是质数，所以13人无法按要求分组，只能每组1人或13人，这不符合多于1人且不多于10人的要求。

三、常见错误理解及纠正

错误1：认为质数都是奇数。
纠正：这句话是错的。例如2是质数，但2是偶数。所以只能说，大于2的质数都是奇数。我们可以这样记：除了2，其余的质数都是奇数，但奇数不一定是质数，比如9、15是奇数却是合数。

错误2：把1当成质数。
纠正：1只有一个因数，不符合质数“有两个因数”的条件。判断质数和合数时，首先看这个数是否大于1。如果小于或等于1，它既不是质数也不是合数。学生常常忘记1的特殊身份，看到只有一个因数的数，就误认为是质数。牢记：1不是质数，也不是合数。

错误3：找因数时漏掉一对，把合数误判为质数。
纠正：例如判断91是不是质数。有的同学只试了2、3、5，发现都不能整除，就认为91是质数。其实还需要试7，因为 $91=7\times13$，所以91是合数。一个合数如果比较大，我们通常只需要用质数去除它，一直试到除数的平方接近这个数为止。如果都没有整除，这个数才是质数。要养成有序找因数的习惯。
