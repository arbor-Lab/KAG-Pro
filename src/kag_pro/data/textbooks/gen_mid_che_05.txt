初中化学 - 碳的单质与二氧化碳

一、 认识碳的单质  
碳的单质是由碳元素组成的纯净物。初中阶段重点学习金刚石、石墨和无定形碳。金刚石透明坚硬，是自然界最硬的物质，可做钻头；石墨灰黑质软，有滑腻感且能导电，可用于铅笔芯和电极。木炭、活性炭等因其疏松多孔，具有吸附能力，用于净水或防毒面具。它们都由碳原子构成，但原子排列方式不同，导致物理性质差异很大，这种现象叫同素异形现象。但它们的化学性质相似，常温下稳定，点燃时都可与氧气反应。  
例题1：为什么金刚石能裁玻璃，而石墨却可以做润滑剂？  
解答：金刚石的碳原子排列成立体网状结构，质硬；石墨的碳原子排列成层状结构，层间易滑动，质软且润滑。这体现了结构决定性质。  
常见错误：认为石墨软就不能导电。纠正：石墨中每个碳原子最外层有4个电子，形成层状结构后留下一个自由移动的电子，所以石墨虽软却具有良好的导电性。

二、 二氧化碳的性质与用途  
二氧化碳（$CO_2$）是无色无味气体，密度比空气大，能溶于水。固态二氧化碳俗称干冰，升华时吸热，可用作制冷剂。它不支持燃烧，也不能供给呼吸，但本身无毒。化学性质主要有：  
1. 与水反应生成碳酸：$CO_2 + H_2O = H_2CO_3$，碳酸使紫色石蕊试液变红。但碳酸不稳定，易分解：$H_2CO_3 = H_2O + CO_2 \uparrow$。  
2. 与石灰水反应：$CO_2 + Ca(OH)_2 = CaCO_3 \downarrow + H_2O$，产生白色沉淀，这是检验二氧化碳的常用方法。  
例题2：如何用化学方法区别氧气和二氧化碳两瓶气体？  
解答：分别倒入少量澄清石灰水，振荡。石灰水变浑浊的原瓶是二氧化碳，无明显变化的是氧气。不能用燃着的木条，因为两者都不支持木条燃烧。  
常见错误：误以为二氧化碳有毒。纠正：二氧化碳无毒，但空气中含量过高会排挤氧气，造成缺氧窒息。进入菜窖前必须做灯火试验。

三、 碳单质与二氧化碳的相互转化  
碳单质在氧气充足时完全燃烧生成二氧化碳：  
$$C + O_2 \xrightarrow{点燃} CO_2$$  
若氧气不足，则产生一氧化碳：  
$$2C + O_2 \xrightarrow{点燃} 2CO$$  
这两个反应都放出热量。另外，在高温下碳单质能还原二氧化碳：  
$$CO_2 + C \xrightarrow{高温} 2CO$$  
这体现了碳的还原性，是工业制取煤气的方法。  
例题3：将一块木炭放入充满二氧化碳的试管并高温加热，反应后剩余气体可能是什么？  
解答：根据 $CO_2 + C \xrightarrow{高温} 2CO$，若木炭足量，二氧化碳全转化成一氧化碳，剩余气体是CO；若木炭不足，剩余气体是CO和未反应完的$CO_2$的混合物。  
常见错误：写碳燃烧方程式时，不看氧气量一律写成生成二氧化碳。纠正：必须根据反应物比例判断产物。氧气足写第一个方程式，不足写第二个，条件均为“点燃”。
