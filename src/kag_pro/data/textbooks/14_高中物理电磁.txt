高中物理 - 电磁学基础

一、电场

电荷周围存在电场。电场强度 E = F/q（单位：N/C）。

点电荷的电场：E = kQ/r²，方向由正电荷指向外。

电场线：从正电荷出发，终止于负电荷。电场线的疏密表示电场的强弱。

二、电势与电势差

电势能：电荷在电场中具有的势能。
电势：φ = Ep/q（单位：伏特 V）

电势差（电压）：U = φ₁ - φ₂
电场力做功：W = qU

三、电容器

电容 C = Q/U（单位：法拉 F），表示电容器容纳电荷的能力。

平行板电容器：C = εS/d
- ε：介电常数
- S：极板正对面积
- d：极板间距

四、恒定电流

欧姆定律：I = U/R（I：电流A，U：电压V，R：电阻Ω）

电阻定律：R = ρL/S
- ρ：电阻率
- L：导体长度
- S：横截面积

电功率：P = UI = I²R = U²/R

焦耳定律：Q = I²Rt（电流通过导体产生的热量）

五、磁场

磁感应强度 B = F/(IL)（单位：特斯拉 T），方向由左手定则判定。

安培力：F = BIL·sinθ（θ为B与I的夹角）

洛伦兹力：F = qvB·sinθ（运动电荷在磁场中受到的力）

常见错误：
- 混淆左手定则和右手定则
- 左手定则：判断安培力和洛伦兹力方向
- 右手定则：判断感应电流方向（楞次定律）
