初中数学 - 实数与二次根式

一、从有理数到实数
在之前的学习中，我们接触到的数都是有理数，比如整数和分数。但实际生活中，有些数的平方等于 $2$，这个数是多少呢？我们发现 $1.4^2=1.96$，$1.5^2=2.25$，$1.41^2=1.9881$……无论怎样用小数逼近，都找不到一个有限小数或无限循环小数，使它的平方恰好等于 $2$。于是我们引入一种新的数，叫做无理数。像 $\sqrt{2}$、$\pi$、$0.1010010001\cdots$（每两个 $1$ 之间依次多一个 $0$）这样无限不循环的小数都是无理数。有理数和无理数统称为实数。实数与数轴上的点一一对应，每一个实数都可以用数轴上的一个点表示出来。实数也可以按大小进行分类：正实数、零、负实数。

二、二次根式的概念与性质
一般地，我们把形如 $\sqrt{a}$（$a\ge 0$）的式子叫做二次根式，其中“$\sqrt{\ \ }$”称为二次根号，$a$ 叫做被开方数。二次根式有意义的条件是 $a\ge 0$，因为在实数范围内，负数没有平方根。

二次根式有两个非常重要的性质：
性质1：$(\sqrt{a})^2 = a$ （$a\ge 0$）。它说明一个非负数的算术平方根的平方等于它本身。
性质2：$\sqrt{a^2} = |a| = \begin{cases} a, & a \ge 0 \\ -a, & a < 0 \end{cases}$。它表示一个数的平方的算术平方根等于这个数的绝对值。

例1：当 $x$ 为何值时，二次根式 $\sqrt{3x-6}$ 有意义？
解：由被开方数 $3x-6 \ge 0$，解得 $x \ge 2$。所以当 $x \ge 2$ 时，该二次根式有意义。

例2：化简 $\sqrt{(-5)^2}$ 和 $\sqrt{(3-\pi)^2}$。
解：$\sqrt{(-5)^2} = |-5| = 5$；因为 $3-\pi < 0$，所以 $\sqrt{(3-\pi)^2} = |3-\pi| = \pi-3$。

常见错误1：误认为 $\sqrt{a^2} = a$ 对一切 $a$ 都成立。
纠正：比如当 $a=-4$ 时，$\sqrt{(-4)^2}=\sqrt{16}=4$，而不是 $-4$。正确结果应该是 $|a|$。一定要先判断 $a$ 的符号，再用绝对值去掉根号。

三、二次根式的运算与化简
二次根式的乘法法则：$\sqrt{a} \cdot \sqrt{b} = \sqrt{ab}$（$a\ge 0$，$b\ge 0$）。除法法则：$\frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}}$（$a\ge 0$，$b>0$）。利用这些法则可以进行化简，我们通常要求最后结果是最简二次根式。最简二次根式满足两个条件：被开方数不含分母；被开方数中不含能开得尽方的因数或因式。

例3：化简 $\sqrt{48} + \sqrt{27} - \sqrt{\frac{1}{3}}$。
解：先把每一项化为最简二次根式。
$\sqrt{48} = \sqrt{16 \times 3} = 4\sqrt{3}$，
$\sqrt{27} = \sqrt{9 \times 3} = 3\sqrt{3}$，
$\sqrt{\frac{1}{3}} = \frac{\sqrt{1}}{\sqrt{3}} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$。
原式 $= 4\sqrt{3} + 3\sqrt{3} - \frac{\sqrt{3}}{3} = \left(4+3-\frac{1}{3}\right)\sqrt{3} = \frac{20}{3}\sqrt{3}$。

常见错误2：误以为 $\sqrt{a+b} = \sqrt{a} + \sqrt{b}$。
纠正：例如 $\sqrt{9+16}=\sqrt{25}=5$，但 $\sqrt{9}+\sqrt{16}=3+4=7$，显然不相等。二次根式的加法只能合并同类二次根式，绝不能错误地拆开被开方数中的和或差。
