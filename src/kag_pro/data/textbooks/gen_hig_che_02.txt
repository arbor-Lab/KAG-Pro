高中化学 - 离子反应

一、离子反应的定义与本质  
在溶液中，有离子参加或生成的反应叫作离子反应。如盐酸与氢氧化钠溶液的反应，实质是 $H^+$ 与 $OH^-$ 结合生成 $H_2O$ 的过程。离子反应的本质是反应物中的某些离子浓度减小，这种减小通常通过生成沉淀、气体或弱电解质（如水、弱酸、弱碱等）来实现。若反应后离子浓度没有发生改变，则不能叫作离子反应，例如 $NaCl$ 溶液与 $KNO_3$ 溶液混合，实际上没有发生化学变化。

二、离子方程式的书写规则  
用实际参加反应的离子符号来表示反应的式子就是离子方程式。书写可归纳为“写、拆、删、查”四个步骤。  
第一步，写出正确的化学方程式，例如硫酸铜溶液与氢氧化钠溶液反应：  
$$CuSO_4 + 2NaOH = Cu(OH)_2 \downarrow + Na_2SO_4$$  
第二步，把易溶于水、易电离的物质拆成离子形式，单质、氧化物、气体、沉淀和水等弱电解质仍用化学式表示。上式中 $CuSO_4$、$NaOH$、$Na_2SO_4$ 都是易溶的强电解质，拆成离子，$Cu(OH)_2$ 是沉淀，保留化学式：  
$$Cu^{2+} + SO_4^{2-} + 2Na^+ + 2OH^- = Cu(OH)_2 \downarrow + 2Na^+ + SO_4^{2-}$$  
第三步，删去方程式两边不参加反应的离子，即等号两边相同的离子 $Na^+$ 和 $SO_4^{2-}$：  
$$Cu^{2+} + 2OH^- = Cu(OH)_2 \downarrow$$  
第四步，检查离子方程式两边各元素的原子个数和电荷总数是否相等。上式左边电荷总数 $(+2)+(-2)=0$，右边是电中性的 $Cu(OH)_2$，电荷守恒，原子也守恒。

三、例题与常见错误辨析  
例题1：写出稀硫酸与氢氧化钡溶液反应的离子方程式。  
解答：化学方程式为 $H_2SO_4 + Ba(OH)_2 = BaSO_4 \downarrow + 2H_2O$。拆写时，$H_2SO_4$、$Ba(OH)_2$ 为强电解质，拆成离子；$BaSO_4$ 是沉淀，$H_2O$ 是弱电解质，保留化学式：  
$$2H^+ + SO_4^{2-} + Ba^{2+} + 2OH^- = BaSO_4 \downarrow + 2H_2O$$  
检查两边电荷与原子均守恒。

例题2：判断离子方程式 $Fe + 2H^+ = Fe^{3+} + H_2 \uparrow$ 是否正确。  
解答：错误。铁与稀酸反应生成 $Fe^{2+}$，不是 $Fe^{3+}$，正确应为 $Fe + 2H^+ = Fe^{2+} + H_2 \uparrow$。学生易误认为铁为金属单质一律生成三价铁，需记住铁与酸、与盐溶液置换时只生成 $Fe^{2+}$，除非使用强氧化性酸如硝酸。

常见错误辨析：  
错误一：将难溶物拆成离子。如写碳酸钙与盐酸反应时，学生误将 $CaCO_3$ 拆成 $Ca^{2+}$ 和 $CO_3^{2-}$。纠正方法：强调“拆”只针对可溶性强电解质，碳酸钙是沉淀，必须写化学式 $CaCO_3$，正确离子方程式为  
$$CaCO_3 + 2H^+ = Ca^{2+} + CO_2 \uparrow + H_2O$$  
错误二：忽视电荷守恒。如写铁与氯化铁溶液反应：$Fe + Fe^{3+} = 2Fe^{2+}$，左边电荷总数为 $+3$，右边为 $+4$，不守恒。纠正方法：要求每一离子方程式写完必须检查两边电荷总量是否相等，正确为  
$$Fe + 2Fe^{3+} = 3Fe^{2+}$$
