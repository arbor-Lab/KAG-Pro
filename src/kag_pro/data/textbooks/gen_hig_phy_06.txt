高中物理 - 平抛运动

一、平抛运动的定义与特点
将物体以一定的初速度沿水平方向抛出，忽略空气阻力，物体只在重力作用下的运动，叫作平抛运动。平抛运动是匀变速曲线运动，加速度恒为重力加速度 $g$，方向竖直向下。它具有两个关键特点：水平方向不受力，做匀速直线运动；竖直方向只受重力，初速度为零，做自由落体运动。这两个方向上的运动彼此独立，同时发生，这就是运动的合成与分解思想。

二、平抛运动的规律与公式
以抛出点为坐标原点，水平初速度 $v_0$ 方向为 $x$ 轴正方向，竖直向下为 $y$ 轴正方向，经时间 $t$ 后：
水平位移 $$x = v_0 t$$
竖直位移 $$y = \frac{1}{2} g t^2$$
水平分速度 $$v_x = v_0$$
竖直分速度 $$v_y = g t$$
合速度大小 $$v = \sqrt{v_x^2 + v_y^2} = \sqrt{v_0^2 + (gt)^2}$$
合速度方向与水平方向夹角 $\theta$ 满足 $$\tan\theta = \frac{v_y}{v_x} = \frac{gt}{v_0}$$
轨迹方程由 $x = v_0 t$ 得 $t = \frac{x}{v_0}$，代入 $y$ 式，得 $$y = \frac{g}{2v_0^2} x^2$$ 平抛运动的轨迹是一条抛物线。

三、例题与常见误区
例题1：一架飞机在离地面高度 $h = 500\,\mathrm{m}$ 处，以 $v_0 = 100\,\mathrm{m/s}$ 的速度水平飞行，投下一枚炸弹。忽略空气阻力，$g$ 取 $10\,\mathrm{m/s^2}$，求炸弹落地时的水平位移。
解：由 $h = \frac{1}{2} g t^2$ 得 $t = \sqrt{\frac{2h}{g}} = \sqrt{\frac{2\times500}{10}}\,\mathrm{s} = 10\,\mathrm{s}$。水平位移 $x = v_0 t = 100\times10\,\mathrm{m} = 1000\,\mathrm{m}$。

例题2：从高度 $h = 20\,\mathrm{m}$ 处以 $v_0 = 5\,\mathrm{m/s}$ 水平抛出一个小球，求小球落地时速度的大小和方向，$g$ 取 $10\,\mathrm{m/s^2}$。
解：竖直落地速度 $v_y = \sqrt{2gh} = \sqrt{2\times10\times20}\,\mathrm{m/s} = 20\,\mathrm{m/s}$。合速度大小 $v = \sqrt{v_0^2 + v_y^2} = \sqrt{5^2 + 20^2}\,\mathrm{m/s} \approx 20.6\,\mathrm{m/s}$。设速度与水平方向夹角为 $\theta$，$\tan\theta = \frac{v_y}{v_0} = \frac{20}{5} = 4$，$\theta = \arctan 4 \approx 76^\circ$。

例题3：一物体以 $10\,\mathrm{m/s}$ 的初速度水平抛出，$1\,\mathrm{s}$ 末物体的位移与水平方向夹角的正切值是多少？$g$ 取 $10\,\mathrm{m/s^2}$。
解：$1\,\mathrm{s}$ 时，$x = v_0 t = 10\,\mathrm{m}$，$y = \frac{1}{2}gt^2 = 5\,\mathrm{m}$。位移与水平方向的夹角 $\alpha$ 满足 $\tan\alpha = \frac{y}{x} = \frac{5}{10} = 0.5$。

常见误区与纠正：
误区一：认为平抛运动中速度方向与水平方向的夹角和位移方向与水平方向的夹角始终相等。正确关系是：任意时刻 $\tan\theta = 2\tan\alpha$（$\theta$ 为速度偏角，$\alpha$ 为位移偏角）。因为 $\tan\theta = \frac{gt}{v_0}$，而 $\tan\alpha = \frac{y}{x} = \frac{\frac{1}{2}gt^2}{v_0 t} = \frac{gt}{2v_0}$，故 $\tan\theta = 2\tan\alpha$。学生常将二者混淆，需通过推导区分。

误区二：误以为水平初速度越大，物体在空中运动时间越长。由 $h = \frac{1}{2}gt^2$ 得 $t = \sqrt{\frac{2h}{g}}$，飞行时间只取决于竖直高度，与水平初速度无关。教师应反复强调两个方向运动的独立性。
