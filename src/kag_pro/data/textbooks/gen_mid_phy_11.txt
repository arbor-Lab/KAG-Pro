初中物理 - 功与功率

一、功
如果一个力作用在物体上，并且物体在这个力的方向上移动了一段距离，我们就说这个力对物体做了功。做功必须同时满足两个条件：一是有力作用在物体上，二是物体在力的方向上通过了一段距离。缺一不可。

功的计算公式为
$$W = Fs$$
其中 $W$ 表示功，$F$ 是力的大小，$s$ 是物体在力的方向上移动的距离。在国际单位制中，力的单位是牛顿（N），距离的单位是米（m），功的单位是焦耳（J），$1\,\text{J} = 1\,\text{N} \cdot \text{m}$。使用公式时要特别注意：代入的 $s$ 必须是沿着力方向的移动距离。如果力的方向与物体运动方向垂直，该力不做功。

例1 小华用20 N的水平推力推动一个木箱，使木箱沿水平地面前进了3 m。求推力所做的功。
解：推力方向水平，木箱移动方向也是水平，$F=20\,\text{N}$，$s=3\,\text{m}$。
$$W = Fs = 20\,\text{N} \times 3\,\text{m} = 60\,\text{J}$$
推力做功60 J。

例2 一个质量为2 kg的苹果从离地面5 m高的树枝上自由落下。苹果受到的重力是多少？重力对苹果做了多少功？（取 $g = 10\,\text{N/kg}$）
解：重力 $G = mg = 2\,\text{kg} \times 10\,\text{N/kg} = 20\,\text{N}$。苹果在重力方向上竖直下落了 $h = 5\,\text{m}$，所以
$$W = Gh = 20\,\text{N} \times 5\,\text{m} = 100\,\text{J}$$
重力做功100 J。若苹果被水平抛出，在水平飞行阶段，重力的方向与移动方向垂直，重力不做功。

二、功率
做功有快慢之分。功率就是表示做功快慢的物理量，定义为功与做功所用时间之比。
$$P = \frac{W}{t}$$
式中 $P$ 为功率，$W$ 为功，$t$ 为时间。功率的主单位是瓦特（W），$1\,\text{W} = 1\,\text{J/s}$，常用单位还有千瓦（kW），$1\,\text{kW} = 1000\,\text{W}$。
当物体做匀速直线运动时，将 $W = Fs$ 代入可得 $P = \frac{Fs}{t} = Fv$，即功率等于力与速度的乘积，使用时须注意 $F$ 与 $v$ 的方向需在同一条直线上。

例3 一台起重机在8 s内将重为4000 N的钢材匀速竖直提升6 m。求起重机提升钢材的功率。
解法一：起重机对钢材的拉力等于钢材重力，$F = 4000\,\text{N}$，$s = 6\,\text{m}$。
$$W = Fs = 4000\,\text{N} \times 6\,\text{m} = 24000\,\text{J}$$
$$P = \frac{W}{t} = \frac{24000\,\text{J}}{8\,\text{s}} = 3000\,\text{W} = 3\,\text{kW}$$
解法二：钢材上升速度 $v = \frac{s}{t} = \frac{6\,\text{m}}{8\,\text{s}} = 0.75\,\text{m/s}$，
$$P = Fv = 4000\,\text{N} \times 0.75\,\text{m/s} = 3000\,\text{W}$$
起重机提升钢材的功率为3 kW。

三、常见错误及纠正
错误1：认为只要物体移动了一段距离，施加在物体上的力就一定做功。
纠正：做功必须满足“在力的方向上移动距离”这一条件。例如，人提着水桶在水平路面上匀速前进，手对水桶的拉力竖直向上，而水桶的运动方向是水平的，两者互相垂直，拉力不做功。只有水桶在竖直方向上升或下降时，拉力才做功。

错误2：认为做功多的物体，功率一定大。
纠正：功率的大小由做功的多少和所用时间共同决定。做功多，但如果用的时间很长，功率反而可能很小。比如，两个人把同样多的砖搬到同一高度，一个人用3分钟完成，另一个人用10分钟完成，前者做功与后者相同，但用时更短，功率更大。分析功率问题时，一定要同时关注功和时间两个因素。
