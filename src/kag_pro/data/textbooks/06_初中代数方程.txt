初中数学 - 代数方程

一、一元一次方程

含有未知数的等式叫做方程。只含有一个未知数，且未知数的最高次数是1的方程叫做一元一次方程。

标准形式：ax + b = 0（a ≠ 0）

解一元一次方程的步骤：
1. 去分母
2. 去括号
3. 移项（把含有未知数的项移到等号一边，常数项移到另一边）
4. 合并同类项
5. 系数化为1

例如：解方程 2x + 3 = 7
移项：2x = 7 - 3
合并：2x = 4
系数化1：x = 2

检验：把 x=2 代入原方程，左边 = 2×2+3 = 7 = 右边，所以 x=2 是方程的解。

二、一元二次方程

只含有一个未知数，且未知数的最高次数是2的整式方程叫做一元二次方程。

标准形式：ax² + bx + c = 0（a ≠ 0）

求根公式（韦达定理相关）：x = (-b ± √(b² - 4ac)) / 2a

其中 Δ = b² - 4ac 叫做判别式：
- 当 Δ > 0 时，方程有两个不相等的实数根
- 当 Δ = 0 时，方程有两个相等的实数根（一个重根）
- 当 Δ < 0 时，方程没有实数根

例如：解方程 x² - 4 = 0
可以因式分解：(x+2)(x-2) = 0
所以 x = 2 或 x = -2
注意：不能遗漏 x = -2 这个根！

常见错误：解 x² - 4 = 0 时只写 x = 2，遗漏了 x = -2。
原因：开平方时，正数的平方根有两个，一正一负。

三、因式分解法解一元二次方程

如果方程可以因式分解，优先使用因式分解法：
1. 将方程化为标准形式 ax² + bx + c = 0
2. 将左边因式分解
3. 令每个因式等于零，分别求解

例如：x² - 5x + 6 = 0
因式分解：(x-2)(x-3) = 0
所以 x-2=0 或 x-3=0，解得 x=2 或 x=3
