初中化学 - 常见的碱及其性质

一、碱的定义与常见的碱
在溶液中电离时，生成的阴离子全部是氢氧根离子（ $OH^-$ ）的化合物叫做碱。碱不一定都能溶于水，像氢氧化铜就是难溶于水的碱。初中阶段接触较多的可溶性碱包括氢氧化钠、氢氧化钙和氨水等。

氢氧化钠（ $NaOH$ ）是白色片状固体，极易溶于水并放出大量的热，在空气中容易吸收水分而潮解，有强烈的腐蚀性，俗称火碱、烧碱、苛性钠。氢氧化钙（ $Ca(OH)_2$ ）是白色粉末状固体，微溶于水，它的水溶液俗称石灰水，固体俗称熟石灰或消石灰，也有腐蚀性。氨水（ $NH_3 \cdot H_2O$ ）则是氨气的水溶液，具有挥发性，闻到刺激性气味。

二、碱的化学性质
碱有一些相似的化学性质，主要是因为它们在溶液中都能电离出共同的 $OH^-$ 离子。

1. 与酸碱指示剂作用：可溶性碱的溶液能使紫色石蕊溶液变成蓝色，使无色酚酞溶液变成红色。需要特别注意的是，不溶于水的碱（如氢氧化铜）无法使指示剂变色。

2. 与某些非金属氧化物反应：碱可以和二氧化碳、二氧化硫等非金属氧化物反应生成盐和水。例如：
$$2NaOH + CO_2 = Na_2CO_3 + H_2O$$
利用这一反应，氢氧化钠可以吸收二氧化碳，因此氢氧化钠固体必须密封保存，防止它潮解后再与空气中的二氧化碳反应而变质。
氢氧化钙与二氧化碳的反应也有重要用途：
$$Ca(OH)_2 + CO_2 = CaCO_3 \downarrow + H_2O$$
实验室常用该反应检验二氧化碳气体，因为生成的碳酸钙会使澄清石灰水变浑浊。

3. 与酸发生中和反应：碱和酸作用生成盐和水，这是酸碱中和的实质（ $H^+ + OH^- = H_2O$ ）。例如：
$$NaOH + HCl = NaCl + H_2O$$

4. 与某些盐溶液反应：可溶性碱能与某些可溶性盐发生复分解反应，生成新碱和新盐，反应须有沉淀、气体或水生成才能发生。例如：
$$2NaOH + CuSO_4 = Cu(OH)_2 \downarrow + Na_2SO_4$$
该反应出现蓝色沉淀，是检验铜离子的常用方法。又比如制取氢氧化钠的反应：
$$Ca(OH)_2 + Na_2CO_3 = CaCO_3 \downarrow + 2NaOH$$

三、示例与常见错误分析
示例1：为什么盛放氢氧化钠溶液的试剂瓶不能用玻璃塞？因为氢氧化钠会与玻璃中的二氧化硅反应生成硅酸钠，使瓶塞黏结。这体现了碱能与某些非金属氧化物反应的性质。
示例2：如何区分氢氧化钠溶液和氢氧化钙溶液？分别通入二氧化碳气体，变浑浊的是氢氧化钙溶液，无明显现象的是氢氧化钠溶液。
示例3：向硫酸铜溶液中滴加氢氧化钠溶液，观察到的现象是有蓝色沉淀生成，反应的化学方程式见上文。若将该沉淀加热，会变黑生成氧化铜。

常见错误1：有些同学认为只要是碱就能使酚酞变红。纠正方法：只有可溶性碱的溶液才能使指示剂变色，不溶性碱如氢氧化铁、氢氧化铜在水中无法电离出足量 $OH^-$ ，不能使酚酞变红。
常见错误2：写碱与非金属氧化物反应的化学方程式时，生成物写成酸。例如误把氢氧化钠与二氧化碳的反应写成 $NaOH + CO_2 = NaHCO_3$ 或直接臆造酸。纠正方法：碱与非金属氧化物反应的通式是“碱加非金属氧化物等于盐加水”，根据化合价正确书写含氧酸盐的化学式，并注意配平。比如氢氧化钠与二氧化碳反应生成碳酸钠，而非碳酸氢钠，只有在特定过量情况下才可能生成酸式盐，初中阶段依通式规范书写即可。
