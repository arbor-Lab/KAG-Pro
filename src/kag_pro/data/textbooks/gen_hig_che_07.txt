高中化学 - 氯及其化合物

一、氯气的性质  
氯气（$Cl_2$）是一种黄绿色、有刺激性气味的有毒气体，密度比空气大，可溶于水（常温下1体积水约溶解2体积 $Cl_2$）。氯原子最外层有7个电子，极易得到一个电子形成 $Cl^-$，因此氯气化学性质非常活泼，具有较强的氧化性。  

（1）与金属反应  
氯气能与绝大多数金属直接化合，生成高价金属氯化物。例如铜在氯气中燃烧：  
$$Cu + Cl_2 \xrightarrow{\Delta} CuCl_2$$  
产物氯化铜溶于水呈蓝绿色。铁与氯气反应生成氯化铁，而不是氯化亚铁：  
$$2Fe + 3Cl_2 \xrightarrow{\Delta} 2FeCl_3$$  

（2）与非金属反应  
氢气在氯气中安静燃烧，发出苍白色火焰，瓶口有白雾（盐酸小液滴）生成：  
$$H_2 + Cl_2 \xrightarrow{\text{点燃}} 2HCl$$  

（3）与水和碱反应  
氯气溶于水会部分与水反应，生成盐酸和次氯酸（$HClO$），这是氯水具有漂白、杀菌作用的原因：  
$$Cl_2 + H_2O \rightleftharpoons HCl + HClO$$  
氯气与氢氧化钠溶液反应常用于尾气吸收：  
$$Cl_2 + 2NaOH = NaCl + NaClO + H_2O$$  

例题1：为什么干燥的氯气不能使干燥的有色布条褪色，而湿润的氯气可以？  
解答：干燥的氯气没有漂白性，湿润的氯气中氯气与水反应生成了具有强氧化性的次氯酸（$HClO$），次氯酸能破坏有机色素的分子结构，从而使其褪色。起漂白作用的物质是 $HClO$，不是 $Cl_2$ 本身。  

常见错误理解1：认为氯气本身具有漂白性。纠正方法：通过对比实验强调，使有色物质褪色的是 $Cl_2$ 与水生成的 $HClO$，干燥 $Cl_2$ 不具备这一性质。  

二、氯水的成分与性质  
新制氯水呈浅黄绿色，这是因为溶解的氯气分子（$Cl_2$）的颜色。氯水中存在多种微粒：分子有 $Cl_2$、$H_2O$、$HClO$；离子有 $H^+$、$Cl^-$、$ClO^-$ 及极少量的 $OH^-$。因此氯水兼有氯气分子、$H^+$ 和 $HClO$ 的多重性质。  

（1）酸性：氯水中 $HCl$ 完全电离，使溶液显酸性（$pH < 7$）。  
（2）氧化性：$HClO$ 具有强氧化性，能杀菌消毒、漂白有色物质。  
（3）不稳定性：次氯酸见光易分解，因此新制氯水需避光保存，久置氯水会逐渐变为稀盐酸，漂白作用消失：  
$$2HClO \xrightarrow{\text{光}} 2HCl + O_2 \uparrow$$  

例题2：新制氯水与久置氯水在成分和性质上有何不同？  
解答：新制氯水含 $Cl_2$、$HClO$ 等，具有漂白性和较强的氧化性；久置氯水中 $HClO$ 完全分解，$Cl_2$ 基本与水反应消耗，最终主要成分为稀盐酸，不再具有漂白性，酸性增强。  

三、氯的重要化合物  
（1）次氯酸钠与漂白粉  
将氯气通入冷的消石灰中可制得漂白粉，其主要成分是氯化钙和次氯酸钙，有效成分是 $Ca(ClO)_2$：  
$$2Cl_2 + 2Ca(OH)_2 = CaCl_2 + Ca(ClO)_2 + 2H_2O$$  
漂白粉在空气中与二氧化碳和水反应生成次氯酸，从而发挥漂白作用：  
$$Ca(ClO)_2 + CO_2 + H_2O = CaCO_3 \downarrow + 2HClO$$  
工业上还常用氯气与氢氧化钠溶液反应制备漂白液，有效成分为 $NaClO$。  

（2）氯离子的检验  
检验溶液中是否含有 $Cl^-$，常用硝酸酸化的硝酸银溶液，生成不溶于稀硝酸的白色沉淀：  
$$Ag^+ + Cl^- = AgCl \downarrow$$  

例题3：某无色溶液加入硝酸银溶液产生白色沉淀，再加稀硝酸沉淀不溶解，能否说明原溶液一定含有 $Cl^-$？  
解答：可以，因为硫酸银等可溶于稀硝酸，碳酸银沉淀会与酸反应溶解，只有氯化银不溶于稀硝酸，因此该现象能证明氯离子的存在。  

常见错误理解2：将漂白粉的有效成分误认为是次氯酸钙与氯化钙的混合物，或认为是次氯酸。纠正方法：强调漂白粉实际漂白时起作用的是次氯酸，但有效成分是指 $Ca(ClO)_2$，它是产生 $HClO$ 的前体物质。
