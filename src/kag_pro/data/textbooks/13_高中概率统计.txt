高中数学 - 概率与统计

一、随机事件与概率

在一定条件下可能发生也可能不发生的事件叫做随机事件。

概率的古典定义：P(A) = 事件A包含的基本事件数 / 基本事件总数

概率的基本性质：
1. 0 ≤ P(A) ≤ 1
2. P(必然事件) = 1，P(不可能事件) = 0
3. P(A∪B) = P(A) + P(B) - P(A∩B)

二、条件概率与独立性

条件概率：P(B|A) = P(A∩B) / P(A)，表示在A发生的条件下B发生的概率。

若 P(A∩B) = P(A)·P(B)，则称事件A与B相互独立。

三、随机变量与分布

离散型随机变量的分布列：列出随机变量每个取值及其概率。

二项分布：X ~ B(n, p)
P(X=k) = C(n,k) · pᵏ · (1-p)ⁿ⁻ᵏ，k=0,1,...,n

正态分布：X ~ N(μ, σ²)
概率密度函数：f(x) = (1/√(2πσ²)) · e^{-(x-μ)²/(2σ²)}

四、统计基础

平均数（均值）：x̄ = (x₁+x₂+...+xₙ)/n

方差：s² = Σ(xᵢ-x̄)²/n，反映数据的离散程度。

标准差：s = √(s²)

五、排列组合

排列：从n个不同元素中取出m个进行排列，A(n,m) = n!/(n-m)!
组合：从n个不同元素中取出m个，C(n,m) = n!/[m!(n-m)!]

常见错误：把排列问题当成组合问题，或反之。排列考虑顺序，组合不考虑顺序。
