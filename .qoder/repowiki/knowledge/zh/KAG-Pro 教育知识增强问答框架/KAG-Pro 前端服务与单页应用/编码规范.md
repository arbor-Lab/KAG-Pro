- 全局单例通过 `get_xxx()` 函数 + 模块级 `_xxx: Optional[...] = None` 变量实现惰性初始化，并在构造后执行一次性资源准备（如 `clear_index` + `index_documents`）。
- 所有 HTTP 端点统一用 `try/except Exception as e` 捕获异常并以 `HTTPException(status_code=500, detail=str(e))` 返回，404 则显式 raise。
- 请求/响应体一律以 Pydantic `BaseModel` 声明（如 `QueryRequest`、`DiagnosisResponse`、`GeneratePaperRequest`），并通过 `response_model=` 约束 OpenAPI 文档。
- 前端通过 `e(s)` 对字符串做 `& < > "` 转义后再拼入 DOM，避免 XSS。
