本模块由三部分组成：
- `server.py`：FastAPI 应用入口，通过 `sys.path.insert(0, .../src)` 把上层 `kag_pro` 包作为依赖引入；使用全局 `_pipeline` / `_knowledge_tree` / `_paper_store` / `_favorite_store` 懒加载单例，避免重复初始化 RAGPipeline（含 ChromaDB 索引）和 LLM Generator。
- `index.html`：零框架的单页应用，内联 CSS + 原生 JS，按 `data-v` 路由在 chat / paper / library 三个视图间切换，通过 `fetch('/api/*')` 调用后端；会话历史与草稿保存在 `localStorage`。
- `generate_textbooks.py`：独立批处理脚本，遍历 `COMPREHENSIVE_OUTLINE` 调用 LLM 生成初高中教材文本，落盘到 `src/kag_pro/data/textbooks`，供 RAGPipeline 索引。

依赖方向单向：frontend → `kag_pro.core.*`（RAGPipeline、PaperGenerator、PaperStore、FavoriteStore、Generator），前端不反向依赖后端。
