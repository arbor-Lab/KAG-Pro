顶层通过单 Python 包 `kag-pro`（`src/kag_pro/`）聚合五个子模块：`core` 提供 `RAGPipeline` 作为唯一对外编排接口；`kg`、`diagnosis`、`datasets` 作为 core 的可选能力插件被 pipeline 调用；`frontend` 是独立 FastAPI 进程，通过 HTTP 调用 core/diagnosis/kg 暴露 REST API。所有子模块共享同一套依赖声明（`pyproject.toml` 中的 openai/dashscope/chromadb/langchain-text-splitters/jieba/pypdf/python-dotenv），并通过 `.env` 注入 LLM 密钥，使核心管线与前端在运行时解耦、在部署时由 `Makefile` 的统一命令（`install-all`、`run-prototype`、`python frontend/server.py`）驱动。
