- 关系类型集中声明于 `KnowledgeGraph.RELATION_TYPES`，新增关系需在此注册并在 `add_relation` 中校验，避免散落的魔法字符串。
- 实体 ID 采用前缀 + 序号的命名约定（如 `math_*`、`phys_*`、`chem_*`、`auto_000`），便于区分来源与语义域。
- 对外暴露的抽取器类以 `build_*` / `extract_*` / `retrieve` 等动词方法组织，内部状态通过 `self._xxx` 私有属性封装，遵循“不可变输入 → 新 KG 对象”的函数式风格。
- 对可选的外部依赖（如 LLM Generator、VectorStore）采用在方法体内 `from ... import ...` 的延迟导入，避免循环依赖与启动开销。
