本模块由三个职责独立的类组成，按数据流向串联：
- `loader.Document`/`DocumentLoader`：以 `Document(text, metadata)` 为统一中间表示，递归扫描目录并按后缀分发到 `_load_txt` / `_load_pdf`（后者使用 `pypdf.PdfReader` 逐页提取），同时通过文件名前缀推断学段、关键词匹配推断学科。
- `splitter.ChineseTextSplitter`：先按正则 `(?:第[一二...]+[章节课]|(?:[一二...]|[0-9]+)[、.)）])` 切分“章节”段落，再对每段调用 `langchain_text_splitters.RecursiveCharacterTextSplitter`（分隔符含中文标点）做二次切块，保持并透传 `Document.metadata`。
- `verifier.FactualVerifier`：构造时依赖外部 `VectorStore` 与 `Embedder`，将答案拆句后逐一用 `vector_store.search(query=claim, top_k=3, threshold)` 检索，按最高相似度是否 ≥ threshold 判定支持与否，汇总得到 `faith_score` 与 HIGH/MEDIUM/LOW 结论。
依赖方向单向：`splitter` → `loader`，`verifier` → `vector_store` + `embedder`；三者之间仅通过 `Document` 对象传递数据，无共享全局状态。
