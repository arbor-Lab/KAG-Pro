- `pipeline.py` 中的 `RAGPipeline` 是唯一的公共编排器，通过组合 `DocumentLoader → ChineseTextSplitter → VectorStore → Retriever → Generator` 构成标准 RAG 链路；可选的 KG 增强路径在 `_init_kg` 中延迟注入 `EntityExtractor` 与 `KGRetriever`。
- 数据流契约由 `loader.Document` 与 `vector_store.VectorStore` 抽象承载：`index_documents` 产出 `Document` 列表写入向量库，`query` 从同一 `VectorStore` 取回片段供 `Generator` 合成答案。
- 验证与诊断能力按需懒加载（`_get_verifier`、`_get_recommender`），避免未启用 KG 时的额外依赖；错误历史在 `diagnose` 中累积并驱动 `ExerciseRecommender` 做练习推荐。
- 外部扩展点（`StageDetector`、`ErrorDiagnoser`、`RAGEvaluator`）通过运行时 import 接入，使 core 仅依赖本目录内的稳定接口，不耦合上层 stage/diagnosis/evaluation 实现。
